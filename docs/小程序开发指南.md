# 🎮 技遇小程序开发指南（一切皆是插件和应用）

> 技遇小程序市场让每个用户都能发布自己的插件/应用（游戏、工具、画板……）。
> 本指南说明**如何在你自己的环境里开发一个小程序**，并发布到平台供所有人使用。

---

## 一、平台定位：一切皆是插件和应用

技遇的「小程序」= 一个**自包含的 HTML 文件**（CSS/JS 全部内联）。
它是运行在技遇沙箱里的微型应用：可以是游戏、计时器、绘画板、计算器……
**人人可开发、人人可发布、人人可运行**。

---

## 二、开发环境（用你自己的电脑即可）

| 工具 | 说明 |
|---|---|
| 任意代码编辑器 | VS Code / 记事本 均可 |
| 本地预览 | 直接用浏览器打开 `.html` 文件即可调试（双击即可） |
| （可选）Live Server | VS Code 装 Live Server 插件，右键 Open with Live Server |
| 无需安装 | 不需要 Node / npm / 框架，一个文件搞定 |

**不需要任何构建工具**：写完一个 `.html` 文件 → 在「技遇 Windows 端 → 消息 → 🛒 小程序 → 发布」上传即完成。

---

## 三、格式规范（务必遵守）

| 项目 | 要求 |
|---|---|
| 格式 | **单个 `.html` 文件**，CSS/JS 全部内联在文件内 |
| 大小 | **≤ 5MB** |
| 禁止 | 外链脚本 `<script src>`、外链样式 `<link>`、内嵌 `<iframe>`、任何网络请求 |
| 资源 | 全部使用内联 CSS 图形 / 内联数据（如 `data:` URI），**不得引用外部图片** |
| 存储 | 运行在沙箱中，**localStorage / sessionStorage / cookie 不可用**（游戏进度请用内存变量） |
| 触屏 | 建议同时支持键盘与触屏（参考示例贪吃蛇） |

### 最小可用模板

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0, user-scalable=no">
<title>我的小程序</title>
<style>
  /* 所有样式内联 */
  body { font-family: -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif; }
</style>
</head>
<body>
  <h1>你好，技遇 👋</h1>
  <script>
    // 所有脚本内联；不要引用任何外部资源
    console.log('小程序运行中')
  </script>
</body>
</html>
```

## 四、桥接协议（与宿主通信）

小程序通过 `window.parent.postMessage` 与宿主（技遇 App）通信。**当前支持的事件**：

### 上报分数（排行榜）

```js
// 游戏结束时调用（score 为数字）
window.parent.postMessage({ type: 'jiyuScore', score: 12345 }, '*')
```

- 上报后自动进入该小程序的**排行榜**（Top 20，所有用户可见）
- 每个账号独立计分，**同账号只保留最高分**（越玩越高，不会越玩越低）
- 排行榜数据接口：`GET /api/apps/:id/scores`（需登录）
- 提交接口：`POST /api/apps/:id/score` `{score, playerName}`（需登录，由宿主自动调用，小程序内无需关心）

> 宿主监听 `message` 事件自动提交，小程序内**不要**自己调网络接口（沙箱内也没有网络）。

### 后续扩展事件（规划）

| 事件 | 说明 | 状态 |
|---|---|---|
| `jiyuScore` | 上报分数进排行榜 | ✅ 已支持 |
| `jiyuSave` | 存档读取/写入 | 🚧 规划中 |
| `jiyuShare` | 分享卡片 | 🚧 规划中 |

## 五、发布流程

1. **开发**：写好自包含 HTML（本地浏览器调试通过）
2. **发布**：Windows 端 → 消息 → 🛒 小程序 → **发布** → 选择 `.html` 文件 + 填写名称/简介/图标
3. **校验**：服务端自动检查（≤5MB / 单文件自包含 / 禁外链 / 名称简介过风控）
4. **上线**：发布后**所有用户**（Windows + iOS）都能在小程序市场搜索到并运行

### 管理
- 发布者可在市场中对自己发布的小程序执行「删除」
- 小程序详情显示作者、大小、运行次数

## 六、运行环境（沙箱说明）

| 端 | 运行方式 | 说明 |
|---|---|---|
| Windows | `<iframe sandbox="allow-scripts">` | 无网络、无父页面访问权限、无存储；键盘需**先点击游戏画面**获得焦点 |
| iOS | WKWebView（注入桥接脚本） | 同上；分数上报通过 messageHandlers 桥接 |

**开发者须知**：
- 页面不可访问父页面 DOM / JS（沙箱隔离）
- 不可发起任何网络请求（完全离线运行）
- 键盘事件：桌面端需先点击 iframe 内部
- 窗口尺寸：约 360×520（win）/ 屏幕宽度（iOS），建议响应式布局

## 七、参考示例：贪吃蛇（随平台预置）

完整源码：`server/src/snake-app.html`（7KB，平台默认示例）

```html
<!-- 关键桥接代码（游戏结束时） -->
<script>
function gameOver() {
  // ...显示结束界面...
  try { window.parent.postMessage({ type: 'jiyuScore', score: score }, '*') } catch (e) {}
}
</script>
```

**示例要点**：
- 键盘（方向键）+ 触屏滑动双控制
- 纯 CSS 图形（canvas + 圆角方块），无外部资源
- 内联样式，单文件运行

## 八、发布检查清单

- [ ] 单个 `.html` 文件，双击浏览器可运行
- [ ] 无 `<script src>` / `<link>` / `<iframe>` / 网络请求
- [ ] 文件 ≤ 5MB
- [ ] 触屏可用（手机上也能玩/用）
- [ ] 名称 ≤ 30 字、简介 ≤ 200 字、图标为 1 个 Emoji
- [ ] 需要排行榜的小程序在结束时 `postMessage({type:'jiyuScore', score})`

## 九、常见问题

| 问题 | 解决 |
|---|---|
| 打开后 JS 不执行 / 白屏 | 检查是否有外链脚本或语法错误；本地浏览器先调试通过 |
| 键盘无法控制 | **先点击游戏画面**获得焦点（沙箱 iframe 特性） |
| 想存进度 | 内存变量即可；持久化存储能力在规划中 |
| 分数没上榜 | 确认调用了 `postMessage({type:'jiyuScore', score})` 且 `score` 是数字 |
| 想被更多人看到 | 名称与简介写清楚，图标选醒目 Emoji |
